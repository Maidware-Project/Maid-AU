# code of conduct

this project is about the software. technical problems get technical
answers - that is the entire scope.

## no politics, no policing

- no ideological or political messaging in code, commits, comments,
  pull requests, issues, or docs - from any side, about anything.
  flags, slogans, causes, elections, wars: if that's what it is,
  it doesn't belong here, no matter which side it's on.
- nobody gets judged, silenced, or rejected for beliefs, identity,
  or affiliations - only contributions get judged, technically.
  bad code gets rejected for being bad code.
- pull requests adding political messaging get denied with a polite
  request to amend them out. repeated ones get closed.

## stay on topic, stay decent

- off-topic and NSFW contributions (issues, PRs, comments, code,
  docs) get rejected. this is a toolbox, not a forum.
- treat everyone neutrally: no arguing, lashing out, drama, or
  vendettas, regardless of who anyone is or believes. disagree
  about code all you like - that's the job.

## why no standard CoC

the big-project codes of conduct have repeatedly been used to
silence feedback and criticism over ideological disagreements.
we won't run that system here. the rule above replaces it: keep
politics out, judge contributions technically, treat people neutrally.
